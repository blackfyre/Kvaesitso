# Device screenshots (task 4.1, 4.2)

Pixel 7, Android 17, debug build, fresh app data (Blackfyre defaults), 2026-10-31. Scaled to half size.

- The Pixel 7 captures in Display P3, so saturated colours sample differently from their sRGB tokens: `bf-accent-text` #ff8a4c (dark) reads as about #f0905a, and #a3390c (light) as about #97401d. Neutral greys sample exactly.
- `dark-menu-caps.png`: the menu shows "SETTINGS" in BF Mono Caps; the accessibility node text (what TalkBack reads) is "Settings".
- `display-large-line-height-*.png`: the typography editor's Display Large preview at 0.90, 0.95 and 1.00 line height (task 4.2).
